## 프로젝트 개요
이 프로젝트는 React를 활용하여 동적이고 효율적인 컴포넌트 기반 웹 애플리케이션을 제작한 서브 프로젝트입니다. React의 상태 관리와 컴포넌트 재사용성을 통해 간결하면서도 유지보수하기 쉬운 코드를 구현하였습니다.

## 사용 기술
- **React**
- **HTML**
- **CSS**
- **JavaScript**

## 주요 기능
- **컴포넌트 기반 구조**: React 컴포넌트를 사용하여 재사용 가능하고 유지보수 쉬운 구조 설계
- **동적 UI 구현**: React의 상태 관리로 동적으로 업데이트되는 사용자 인터페이스 구현
- **SPA (Single Page Application)**: React Router를 사용하여 페이지 리로드 없이 부드러운 화면 전환 구현
